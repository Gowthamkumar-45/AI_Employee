# Monitoring Guide

This file explains how to monitor AI employee progress visually and keep the CRM updated.

## Purpose

Track lead progress in a way that is visible and easy to review.

## Visual tracking

- use a CRM, spreadsheet, or dashboard that shows pipeline stages visually
- each lead should have a status field: scouted, qualified, outreach, follow-up, booked, met, won, lost
- show key fields like lead name, company, role, contact info, next step, and last update

## Data sources

- memory/pipeline.md is the source of truth for status and notes
- updates should be reflected in the CRM or dashboard after each change
- use Slack or email for closed-won / closed-lost notifications

## Recommended tools

- Freshworks CRM for visual pipeline tracking and stage management
- Airtable, Notion, or Google Sheets for visual pipelines
- Trello, Asana, or Monday for kanban-style stage tracking
- any CRM that can display stage boards and update in real time

## How to use

- after every lead interaction, update memory/pipeline.md and the visual dashboard
- keep the CRM board aligned with the pipeline stages
- review the dashboard regularly to see where each lead is in the process
- make sure the AI employee can report progress against the visual board
