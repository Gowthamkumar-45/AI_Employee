# Objections Guide

This file stores common pushback and how to handle it.

## Common objections

- **We already have a solution**
  - response: ask what is working, what is missing, and where they wish the current setup was easier.

- **Not interested right now**
  - response: acknowledge it, offer to share a short note or case study, and ask when it would be okay to follow up.

- **Budget is tight**
  - response: ask what budget range makes sense and whether a smaller pilot or phased implementation would help.

- **We are too early / too small**
  - response: explain how startupculture products can start small and scale with the company.

- **Send me info**
  - response: agree to send a short note, then ask a quick qualifying question to keep the lead engaged.

## Handling the objection

- listen to the lead and restate the concern
- keep the response brief and relevant
- always link back to a real business outcome or product value
- note the objection and any follow-up commitment in memory/pipeline.md
