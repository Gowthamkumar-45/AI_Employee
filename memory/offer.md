# Offer Guide

This file stores the offer structure and product positioning for leads.

## Offer components

- **Product focus**
  - what startupculture builds and how it helps early-stage software businesses

- **Value props**
  - product speed
  - automation for launching or scaling
  - reduced manual work and faster delivery

- **Offer types**
  - discovery call
  - pilot engagement
  - custom product delivery

## Use

- use this file as a reference when creating outreach or follow-up messages
- keep offers simple and aligned to the lead's stage and needs
- record any offer details in memory/pipeline.md
